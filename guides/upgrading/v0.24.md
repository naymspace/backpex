# Upgrading to v0.24

## Bump Your Deps

Update Backpex to the latest version:

```elixir
defp deps do
  [
    {:backpex, "~> 0.24.0"}
  ]
end
```

## Backpex extensions can use your application's web helpers

Before v0.24, the `BackpexWeb` entrypoints for item actions, filters and metrics called `use Phoenix.Component`. An
extension that also used `use MyAppWeb, :html` for your application's Gettext backend, components or verified routes
set up `Phoenix.Component` twice. Elixir 1.20 warns about the duplicate functions this defines, so compiling with
`--warnings-as-errors` failed.

The entrypoints `BackpexWeb, :item_action`, `BackpexWeb, :filter` and `BackpexWeb, :metric` now import
`Phoenix.Component`. This also applies to custom filters based on `Backpex.Filters.Select`,
`Backpex.Filters.MultiSelect`, `Backpex.Filters.Boolean` and `Backpex.Filters.Range`. You can add
`use MyAppWeb, :html` before or after them:

```elixir
defmodule MyAppWeb.ItemActions.Archive do
  use BackpexWeb, :item_action
  use MyAppWeb, :html

  # ...
end
```

Extensions that only use `~H` and the helpers of Backpex need no change. If an item action, filter or metric declares
its own function components with `attr` or `slot`, add `use MyAppWeb, :html` or `use Phoenix.Component` to it.

## Custom fields can use your application's LiveComponent entrypoint

Custom fields are LiveComponents, so they can't add `use MyAppWeb, :html`. To use your application's Gettext backend,
components or verified routes in a field, pass your application's LiveComponent entrypoint to `use Backpex.Field`:

```elixir
use Backpex.Field,
  config_schema: @config_schema,
  live_component: {MyAppWeb, :live_component}
```

The entrypoint replaces the `use Phoenix.LiveComponent` of Backpex, so it has to set up a LiveComponent, as the
`:live_component` entrypoint Phoenix generates does. Fields without the option keep the setup of Backpex.

A field now fails to compile if it isn't a LiveComponent or if it sets up `Phoenix.Component` a second time, for example
with `use MyAppWeb, :html` or `use Phoenix.Component`. Remove the second setup and use the `live_component` option
instead.
