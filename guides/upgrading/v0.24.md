# Upgrading to v0.24

## Bump Your Deps

Update Backpex to the latest version:

```elixir
defp deps do
  [
    {:backpex, "~> 0.24.0"}
  ]
end
```

## `postgrex` is an optional dependency and `phoenix_html_helpers` is gone

Backpex used each of the two packages in one place: `postgrex` to recognize a foreign key violation when deleting
items, `phoenix_html_helpers` to render the hidden inputs of the `Backpex.Fields.HasManyThrough` form. Both places work
without the package now, so Backpex no longer adds them to your application.

Backpex still needs PostgreSQL. An application with an `Ecto.Adapters.Postgres` repository lists `postgrex` itself, as
`mix phx.new` generates it; make sure it is in your `mix.exs`:

```elixir
defp deps do
  [
    {:postgrex, ">= 0.0.0"}
  ]
end
```

If your own code calls `PhoenixHTMLHelpers` and got the package only through Backpex, add it too:

```elixir
defp deps do
  [
    {:phoenix_html_helpers, "~> 1.0"}
  ]
end
```
